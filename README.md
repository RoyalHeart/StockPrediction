# StockPrediction

Stock prediction using CNN, LSTM, and DNN.
Currently predicting VN30 Stocks.

The dataset is from three different sources:

- [Cafef](https://liveboard.cafef.vn/)
- [SSI](https://iboard.ssi.com.vn/)
